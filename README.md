## ऑफ़लाइन लाइब्रेरी

```sh
git clone https://github.com/toxictest/ssc_cgl.git
```

डाउनलोड किए गए `ssc_cgl` फ़ोल्डर की [`index.html`](index.html) ब्राउज़र में खोलें। फ़ोल्डर का ढाँचा जस का तस रखें ताकि HTML और PDF के लिंक काम करें। कोई build या install ज़रूरी नहीं है।

> यह तैयारी के लिए बनाया गया स्वतंत्र अध्ययन संग्रह है, SSC का आधिकारिक प्रकाशन या उत्तर-कुंजी नहीं।
